# Issue Tracker

Issues are tracked in GitHub Issues for this repo (`O-Marsters-1997/job-scraper`).

## Reading issues

```bash
gh issue list
gh issue view <number>
```

## Creating issues

```bash
gh issue create --title "..." --body "..."
```

## Updating issues

```bash
gh issue edit <number> --add-label "..."
gh issue close <number>
```

## Linking

Reference issues in commit messages and PR descriptions as `#<number>`.
